# ios26_bottom_navigationbar Example

An interactive demo application showcasing the **`ios26_bottom_navigationbar`** package with real-time controls.

## Features Demonstrated

- **Light & Dark Mode**: Dynamic theme switching showcasing frosted glass adaptation.
- **Accent Color Picker**: Live switching between Apple System Purple, Apple Blue, Green, Orange, and Pink.
- **Container Border Controls**: Real-time slider for border strength (0.0 to 4.0 px) and custom color choice chips.
- **Selected Item Border Controls**: Slider for selected item indicator border strength and custom color chips.
- **Badges**: Interactive toggle for numeric (`badgeCount: 2`), textual (`badgeText: 'NEW'`), and status dot (`showBadge: true`) badges.
- **Blur Intensity**: Live slider adjusting backdrop filter blur sigma (0.0 to 50.0 px).
- **Soft Ambient Fade**: Scrollable list demonstrating content passing seamlessly underneath the floating glass capsule.

## Running the Example

Run on any supported Flutter platform:

```bash
# Mobile (Android / iOS)
flutter run

# Web
flutter run -d chrome

# Desktop (Windows / macOS / Linux)
flutter run -d windows
```
